# Food Delivery Webpage (Group 2 - Project 8)

A vibrant, fully responsive food delivery platform landing page built with **pure HTML5 and CSS3** (No JavaScript or external frameworks).

## 🚀 Project Overview
This project satisfies all requirements for **Group 2 (Project 8)**:
- **Food Categories Grid**: Category browsing with custom visual cards (Pizzas, Burgers, Biryani, Sushi, Bowls, Desserts).
- **Popular Dishes Section**: Detailed food cards featuring dish titles, restaurant affiliations, rating counters, pricing with discounts, and *"Add to Order"* buttons.
- **Restaurant Cards Section**: Showcasing top-rated partner kitchens with delivery times, price indicators, distance metrics, and cuisine specialties.
- **Special Offers & Deals**: Highlighted promotional banner featuring coupon codes, discount callouts, and limited-time deals.
- **Hero & Search Box**: Instant search layout with delivery statistics and interactive CTA triggers.
- **Responsive Footer**: Multi-column footer covering discover links, safety policies, business hours, and helpline details.

## 🛠️ Built With
- **HTML5**: Semantic elements (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`).
- **CSS3**:
  - CSS Custom Variables for uniform color palettes and spacing.
  - CSS Grid & Flexbox architectures for flexible multi-column layouts.
  - Pure CSS checkbox-toggle mobile drawer menu.
  - Hover micro-interactions and elevation drops.
  - Google Fonts (`Plus Jakarta Sans`).
